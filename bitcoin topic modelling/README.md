Bitcoin Tweet Topic Modelling

Project Overview

This project explores the main themes discussed in Bitcoin-related tweets and investigates how these themes vary over time. The objective was to discover recurring topics in social media conversations using unsupervised text analysis rather than predictive modelling.

Tools and Technologies

Python

Pandas and NumPy

Natural Language Processing (NLP) techniques

Topic modelling libraries

Google Colab

Methodology

The workflow involved auditing the dataset, filtering tweets, removing duplicates, preprocessing text, and applying topic modelling techniques to discover recurring themes. The resulting topic assignments were examined to understand the content and distribution of topics in the Bitcoin conversation.

Project Outputs

The project produced a processed tweet corpus and topic assignments that can be used to explore the discovered themes and their distribution over time.

Skills Demonstrated

Data cleaning, text preprocessing, Natural Language Processing, unsupervised learning, topic interpretation, and social media data analysis.
