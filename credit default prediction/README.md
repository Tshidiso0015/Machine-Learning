Credit Default Prediction

Project Overview

This machine learning project investigates the prediction of credit default using customer and loan-related data. The objective was to prepare the data, develop classification models, and evaluate their ability to distinguish between customers who default and those who do not.

Tools and Technologies

Python

Pandas and NumPy

Scikit-learn

XGBoost

Google Colab

Methodology

The workflow covered data quality checks, missing-value treatment, class imbalance analysis, and model development. Logistic Regression, Random Forest, and XGBoost were used to explore different classification approaches. The project also considered weighted modelling techniques to address the imbalance between default and non-default cases, with separate test datasets used for out-of-sample and out-of-time evaluation where applicable.

Project Objectives

The project aimed to compare classification approaches and examine model performance on different evaluation datasets, with particular attention to the challenges of predicting the less frequent default class.

Skills Demonstrated

Data preprocessing, classification, feature analysis, class imbalance handling, model evaluation, and machine learning with Python.
