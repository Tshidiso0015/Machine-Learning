Bayesian Network Analysis

Project Overview

This project investigates relationships between variables influencing customer perceptions and purchase intention using exploratory data analysis and Bayesian Networks. The aim was to examine relationships in the data and compare expert-defined relationships with a network learned from the dataset.

Tools and Technologies

Python

Pandas and NumPy

Data visualisation libraries

Bayesian Network libraries

Google Colab

Methodology

The analysis included data exploration, correlation analysis, heatmap interpretation, and Bayesian Network modelling. An expert-defined Directed Acyclic Graph (DAG) was compared with a data-learned DAG to investigate similarities and differences in the relationships between variables.

Key Findings

The analysis highlighted relationships between purchase intention and factors such as price sensitivity, convenience, empathy, and the physical environment. The comparison of network structures illustrated how expert knowledge and data-driven learning can produce different representations of variable relationships.

Skills Demonstrated

Exploratory data analysis, correlation analysis, Bayesian Networks, DAG interpretation, and analytical reasoning.
